We use **Vercel Web Analytics** and **Vercel Speed Insights** to collect anonymous usage and performance data (page views, Web Vitals). These are first-party Vercel tools, not advertising trackers.

- **Theme:** stored in browser `localStorage` (`nuxt-color-mode`), not a cookie.
